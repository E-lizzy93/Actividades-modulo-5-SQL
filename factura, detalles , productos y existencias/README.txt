# Proyecto: Sistema de Facturación

## Descripción
Script de base de datos relacional para gestión de productos, existencias y facturación.

## Estructura
- script_facturacion.sql: Código DDL y DML para la creación y carga de datos.
- /img: Pantallazos de los resultados de las consultas (Puntos 6, 8, 9, 10 y 11).
- backup_sistema_ventas.sql: Respaldo completo de la base de datos.

## Motor de base de datos
- Sistema: PostgreSQL
- Versión: (puedes verificarla en tu pgAdmin en el menú Help > About)

## Instrucciones de ejecución
1. Ejecutar el script 'script_facturacion.sql' en pgAdmin.
2. Consultar las capturas de pantalla en la carpeta '/img' para ver los resultados esperados.
